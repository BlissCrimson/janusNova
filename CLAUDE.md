# Janus Nova

## Project

Janus Nova ist eine Werbeagentur (advertising agency) spezialisiert auf Textilveredelungen, mit unter anderem Trenferpresses, Folienschnitte für Tetilien, Fenster, Autos und anderes. **Es wird keine Schilder-/Lichtreklameherstellung angeboten oder durchgeführt.**

## Tech Stack

- pnpm
- Vite
- Typescript
- SASS/SCSS

## Konventionen

- Kommentiere auf Englisch
- Variablen auf Englisch camelCase

## Regeln

- Installiere keine npm packages selber
- Jede Änderung in logs/debug.log dokumentieren
- Keine neuen Dateien ohne Rückfrage anlegen

## Verhalten

- Wenn Anforderungen unklar sind: nachfragen, nicht raten
- Lieber eine kurze Rückfrage als falsch umsetzen
- Bei größeren Aufgaben erst den Plan zeigen, dann umsetzen
